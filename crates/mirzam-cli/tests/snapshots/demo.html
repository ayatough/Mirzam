Mirzam

Markdown で書く、第三のスライドツール

自己紹介は 30 秒で切り上げる

なぜ作るのか

既存ツールの限界

  • レイアウト調整が苦行
  • 動画が貼れない
  • ページが増えると重い
  • 独自記法の学習コスト

Mirzam のゴール

  • 見たまま ASCII レイアウト
  • HTML ネイティブ = 動画 OK
  • ページ単位の差分レンダリング
  • CommonMark 互換

性能目標

120 ページ編集時の反映速度: 850ms → 95ms(9 倍)

差分レンダリングにより、変更したスライドだけを再処理する。

数式もそのまま: Tupdate=O(1)(デッキサイズに依存しない)

差分レンダリングの数値は roadmap の実測表を参照

図形とコネクタ

  • 図形はページ座標(%)で宣言する
  • 本文中の パーサ や レンダラ から、図の要素へ矢印を張れる
  • コネクタの端点は表示時に解決されるため、ウィンドウサイズやレイアウトが変わっても自動で追従する

connect はランタイムで毎回ルーティングされる(リサイズしても矢印がついてくる)

アーキテクチャ(分割ファイルの例)

Markdown → AST → Deck IR → Scene Graph → HTML / PDF

  • このスライドは ![[sections/architecture.md]] で親デッキに埋め込まれている
  • コアは Rust、エディタ・ブラウザへは WASM で同一エンジンを配布
  • レイアウトはペインの矩形まで、テキスト組版はブラウザに委譲
