How it works

One engine, everywhere you write

The parser and renderer are one Rust core, compiled twice: a native binary for the CLI and WebAssembly for editors and browsers.

Same input, same pixels - terminal, VS Code, or a phone.

Performance

Deck size stops mattering

2.3 ms
