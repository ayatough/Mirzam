Motion, written down

Press → to walk through. Every animation on the following slides is three lines of Markdown, and none of it is needed to read the deck.

The deck-wide transition is slide-left; individual slides override it below.

The idea

Animation is a timeline, not a plugin

An anim block compiles to a timeline embedded in the slide — triggers, targets, effects and easing all resolved at build time, so the runtime plays a curve instead of computing one.

Press → twice.

Entrances

One line, one movement

```anim
[enter]   .m-title : chars fade-in 500ms stagger=25ms
[click 1] .m-a     : slide-in 400ms dir=up
[click 2] .m-b     : wipe-in 500ms dir=right
[click 3] .m-c     : zoom-in 400ms ease=out-back
```

→ plays the next one.

slide-in — arrives travelling

wipe-in — uncovered by an edge

zoom-in — grows into place

chars splitting happens at build time; the runtime only selects the spans.

Charts

Bars that grow as you talk

Every mark already has an id — and the id names the bar and its value label, as one group — so a bar rises with its number on top:

[click 1] #rev-0-0 : wipe-in dir=up
[click 1] #rev-1-0 : wipe-in dir=up delay=80ms

Growth is broad, not one region carrying the quarter.

Diagrams

A diagram that draws itself

Shapes carry ids, and draw animates a stroke from nothing to its full length.

[click 1] #ingest : pop 350ms
[click 2] #a1     : draw 500ms

Each box lands, then the arrow reaches for the next one.

Five clicks: box, arrow, box, arrow, box. The caption follows on its own.

Images

Photos come and go

A pane holding a photo is a target like any other. Each one arrives on its own click, and none of them leaves — stepping ← takes them back off in the order they came.

Three photos, three clicks, three different entrances.

Page turns

This slide arrives by wiping

The deck turns pages with transition: slide-left. A slide overrides its half of that with an ordinary whole-slide track — this one wipes in and irises out:

[enter] slide : wipe-in 450ms dir=right
[exit]  slide : iris-out 450ms

none, fade, slide-*, wipe-*, zoom and iris are the deck-wide names.

The rule

Motion is something a deck gains

Elements are laid out in their final state. The runtime is the only thing that ever puts one in its starting state, so a deck read without JavaScript — and the PDF export, which ships none — shows every slide fully revealed.

Under prefers-reduced-motion the reveals still happen and stepping still works. Only the movement is dropped.

Effects

Things you do, not things the deck does

An effects block binds a key to a flourish. Press one; Esc clears it.

Key
1 flash
2 shake
3 speed lines
4 explosion
e emoji
c confetti
m a comment sweeps past

These never reach the PDF.

An animation is part of the document — ordered, exported, the same every time. An effect is part of the performance. Nothing is lost if you never press the key.
